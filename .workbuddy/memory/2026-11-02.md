# 2026-11-02

## 从零搭建「云居租房」租赁管理系统（Rent System）

**技术栈**：Next.js 15 App Router + React 19 + TypeScript(strict) + Tailwind 3；图表全部手写 SVG，无 ECharts 等第三方图表依赖。

**架构决策**
- 数据层用本地 JSON 文件（`.data/db.json`）+ 原子写入（tmp + rename）+ globalThis 内存缓存；首次启动由 `lib/seed.ts` 生成演示数据（3 栋 / 60 房 / 44 租客 / 44 合同 / 174 期账单 / 11 工单）。后续换 Prisma/Postgres 只需替换 `lib/db.ts` 与 `lib/queries.ts`。
- 鉴权：Node crypto HMAC-SHA256 签名 Cookie（7 天）+ scrypt 密码哈希；`middleware.ts` 仅校验 Cookie 存在，真实校验在 server layout / route handler；登录接口内存限流 10 次/5 分钟。
- 服务端组件直读数据渲染，客户端组件通过 Route Handlers 变更后 `router.refresh()`，不引入 SWR/React Query。
- 统计聚合集中在 `lib/queries.ts`（RoomView/ContractView/BillView/TenantView/WorkOrderView），页面不直接拼装业务字段。

**业务规则（易踩坑）**
- 账单按付款周期拆分，应缴日 = 账期开始 + 5 天宽限；末期不足 10 天并入上一期，避免 1 天零碎账单；**只为已开始账期生成账单**，未来账期由「生成下期账单」补充。
- 退租时若同房间还有其他覆盖今日的生效合同（续租场景）则房间保持出租，否则置空置并清理退租日后未收账单。
- 续租合同未生效时不覆盖 room.currentContractId。
- 删除保护：有生效合同不可删房；有收款记录的房间/合同不可删（财务留存）；至少保留 1 名启用管理员。
